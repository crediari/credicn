Use `variant` to select the message and illustration for the error. Available variants are `generic`, `not-found`, `server-error`, `forbidden`, `unauthorized`, `offline`, and `maintenance`.

```tsx
import { GenericErrorPage } from "@/components/ui/generic-error-page";

<GenericErrorPage
  variant="not-found"
  buttons={[
    { label: "Back to home", url: "/" },
    { label: "Contact support", url: "/support", variant: "outline" },
  ]}
/>
```

All content and actions are optional. Omit `buttons` for a purely informative state, or override the preset copy when the context needs a more specific message.

```tsx
<GenericErrorPage
  variant="server-error"
  title="Could not load the report"
  description="Your data is safe. Try again in a few minutes."
/>
```

Pass `illustration` to replace the built-in visual with any React node.
