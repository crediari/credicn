A ready-to-use notification center inspired by CrediDesk, independent of routing, global context,
and backend services. The bell trigger shows the unread count; the dialog organizes read and
unread notifications; the preferences area controls delivery by category.

```tsx
import { NotificationCenter } from "@/components/ui/notification-center";

<NotificationCenter
  notifications={notifications}
  preferences={preferences}
  onNotificationOpen={(notification) => {
    if (notification.href) navigate(notification.href);
  }}
  onMarkAsRead={(notification) => markAsRead(notification.id)}
  onMarkAllAsRead={() => markAllAsRead()}
  onPreferenceChange={(preference, enabled) =>
    updatePreference(preference.id, enabled)
  }
/>;
```

## Notification Format

The component expects normalized data. Keep navigation, queries, and persistence in the app.

```tsx
const notifications = [
  {
    id: "notification-id",
    title: "New ticket assigned",
    description: "Ticket #4821 needs an initial response.",
    createdAt: new Date(),
    read: false,
    tone: "info",
    metadata: "Support",
    href: "/tickets/4821",
  },
];
```

`tone` accepts `default`, `info`, `success`, `warning`, and `error`. Use `icon` to override the
category’s default icon. `description` is rendered as text, preventing API-supplied HTML from
being injected directly into the interface.

## Delivery Preferences

The preferences tab appears when `preferences` contains items. The consumer controls the state,
allowing changes to be persisted through an API and rolled back when a request fails.

```tsx
const preferences = [
  {
    id: "mentions",
    label: "Mentions and replies",
    description: "Notify me when someone mentions me.",
    enabled: true,
  },
];
```

Use `pendingPreferenceIds` to disable only the switches currently being saved.

## Asynchronous Operations

- `loading` shows the list’s loading state.
- `error` and `onRetry` provide error recovery.
- `pendingNotificationIds` tracks individual read operations.
- `markingAllAsRead` tracks batch read progress.
- `open`, `defaultOpen`, and `onOpenChange` support controlled and uncontrolled dialogs.
- `closeOnNotificationOpen={false}` keeps the dialog open when selecting a notification.
- `formatTimestamp` overrides the default relative timestamp formatting.
