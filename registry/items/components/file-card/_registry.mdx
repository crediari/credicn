`FileCard` follows the composition of shadcn/ui’s official `Attachment`. It displays files or
images with media, a name, metadata, independent actions, and the full upload lifecycle.

```tsx
import { FileTextIcon, XIcon } from "lucide-react";

import {
  FileCard,
  FileCardAction,
  FileCardActions,
  FileCardContent,
  FileCardDescription,
  FileCardMedia,
  FileCardTitle,
} from "@/components/ui/file-card";

<FileCard>
  <FileCardMedia>
    <FileTextIcon />
  </FileCardMedia>
  <FileCardContent>
    <FileCardTitle>contract.pdf</FileCardTitle>
    <FileCardDescription>PDF · 2.4 MB</FileCardDescription>
  </FileCardContent>
  <FileCardActions>
    <FileCardAction aria-label="Remove contract.pdf">
      <XIcon />
    </FileCardAction>
  </FileCardActions>
</FileCard>;
```

## Composition

```text
FileCard
├── FileCardMedia
├── FileCardContent
│   ├── FileCardTitle
│   └── FileCardDescription
├── FileCardActions
│   └── FileCardAction
└── FileCardTrigger
```

Use `FileCardGroup` to arrange multiple attachments in a horizontal row with scrolling and snap.

## States

The `state` prop accepts `idle`, `uploading`, `processing`, `error`, and `done`. Uploading and
processing states pulse the title; errors use destructive styling; the idle state uses a dashed
border. Describe the error in `FileCardDescription` so the state does not rely on color alone.

```tsx
<FileCard state="uploading">
  <FileCardMedia>
    <FileTextIcon />
  </FileCardMedia>
  <FileCardContent>
    <FileCardTitle>documents.zip</FileCardTitle>
    <FileCardDescription>Uploading · 64%</FileCardDescription>
  </FileCardContent>
</FileCard>
```

## Images and Orientation

Use `variant="image"` on `FileCardMedia` for a thumbnail and `orientation="vertical"` on the card
to stack media and content.

```tsx
<FileCard orientation="vertical">
  <FileCardMedia variant="image">
    <img src="/photo.png" alt="Photo preview" />
  </FileCardMedia>
  <FileCardContent>
    <FileCardTitle>photo.png</FileCardTitle>
    <FileCardDescription>PNG · 820 KB</FileCardDescription>
  </FileCardContent>
</FileCard>
```

## Sizes and Triggers

`size` accepts `default`, `sm`, and `xs`. `FileCardTrigger` creates an interactive area over the
card without blocking its actions. It renders a button by default or another element through
`asChild`. Always provide an `aria-label` for the trigger and icon-only actions.

```tsx
<FileCard size="sm">
  {/* media, content, and actions */}
  <FileCardTrigger aria-label="Preview contract.pdf" />
</FileCard>
```
