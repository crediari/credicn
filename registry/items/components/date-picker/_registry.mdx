Use the default type for a single date. Future days are disabled in this mode.

```tsx
import { DatePicker } from "@/components/ui/date-picker";

<DatePicker value={date} onChange={setDate} />
```

Set `type="range"` to select a start and end date. The calendar displays two months and uses the range-specific placeholder automatically.

```tsx
import type { DateRange } from "react-day-picker";

const [period, setPeriod] = useState<DateRange | undefined>();

<DatePicker type="range" value={period} onChange={setPeriod} />
```
