Pass `username` and an optional `userimage`. Full names use the initials of the first and last
names; single names, such as `John`, use only `J`. Extra whitespace is ignored, and initials
are normalized to uppercase.

```tsx
import { UserAvatar } from "@/components/ui/user-avatar";

<UserAvatar username="Ana Costa" userimage={null} />
<UserAvatar username="John" userimage={null} />
```

## Avatar Group

`UserAvatarGroup` creates overlapping groups and reuses the same gradient fallback, with light
and dark tones derived from `primary` and text in the host theme’s `primary-foreground`. Use
`max` to limit visible avatars; the remainder automatically appears as `+N`.

```tsx
import { UserAvatarGroup } from "@/components/ui/user-avatar";

<UserAvatarGroup
  users={[
    { id: 1, username: "Ana Costa", userimage: null },
    { id: 2, username: "John", userimage: null },
    { id: 3, username: "Maria Silva", userimage: "/avatars/maria.jpg" },
    { id: 4, username: "Carlos Oliveira", userimage: null },
  ]}
  max={3}
  size="default"
/>
```

The `sm`, `default`, and `lg` sizes apply to all avatars and the counter. Customize them with
`avatarClassName`, `overflowClassName`, or `renderOverflow`.

```tsx
<UserAvatarGroup
  users={team}
  max={4}
  size="lg"
  renderOverflow={(remaining) => `${remaining} others`}
/>
```
